# CEZERİ V5

Türkçe sesli yapay zeka asistanı. Yaşlı kullanıcılar ve teknjiden uzak kaan vey anu anamakta zorlanan kişiler için basit anlatım yapar.

## Kurulum

1. `pip install -r requirements.txt`
2. `.env.example` dosyasını kopyalayıp adını `.env` yap
3. console.groq.com/keys adresinden ücretsiz anahtar al ve `.env` içine yaz
4. `python "Cezeri V5.py"`

## Uyarı

Bu program sesli komutla bilgisayarı kapatabilir ve klavyeyi otomatik kontrol eder.
Sadece kendi bilgisayarında, dikkatli kullan.
